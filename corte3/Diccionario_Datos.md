







1)	¿Qué ROL es el encargado de capturar estos datos? (Ej: Recepcionista, Administrador, Cliente).
El rol encargo es el administrador de base de datos, ya que gestiona, registrar y supervisar la información de los productos dentro del sistema, asegurando que los datos sean correctos y estén actualizados
2)	¿Qué FUNCIÓN de validación debe realizar el sistema automáticamente?
I.	verificar que los campos que son obligatorios estén completos
II.	validar que el precio sea numérico y mayor a 0
III.	validar que el stock sea un numero entero 
IV.	evitar registros duplicados
V.	verificar el formato correcto de textos y fechas

3)	¿Qué sucede con la información del sistema si este Rol no cumple su Función?
I.	La información queda incompleta o incorrecta
II.	Se pueden generar errores en el inventario y reportes
III.	El sistema pierde confiabilidad
IV.	Se puede perder información o se puede incluso duplicar
